## Selected projects

### [OmegaFlux](https://github.com/Curiosit/OmegaFlux)
Machine-learning surrogate for climate-based daylight simulation.

Predicts point-by-point daylight performance directly from room geometry using gradient-boosted trees and geometric view descriptors. The model runs in the browser through ONNX and is approximately 200× faster than the Radiance simulations used to train it.

`Python` `XGBoost` `ONNX` `Radiance` `Grasshopper` `TypeScript`

---

### [goeko.gha](https://github.com/Curiosit/goeko.gha)
Grasshopper plugin providing direct access to environmental product declarations from the German **ÖKOBAUDAT** database.

`C#` `Grasshopper` `REST API` `LCA`

---

### [LLM-assisted IFC data enrichment](https://github.com/Curiosit/circular-gh-ifc-ai)
Research workflow using large language models to reconstruct and enrich IFC data for the circular reuse of prefabricated building elements.

Published as accompanying software to a 2026 *Journal of Building Engineering* article.

`IFC` `Grasshopper` `Python` `LLM`

---

### [SLAD.ai 3D](https://github.com/Curiosit/slad.ai-3d-ifc-co2-calculator)
Experimental browser-based carbon assessment tool for IFC models.

`TypeScript` `React` `Three.js` `IFC.js` `Firebase`

---

### [Machine Learning for Building Carbon Footprint](https://github.com/Curiosit/PhD-PredictingCarbonFootprintOfBuildings)
Research code from my PhD work on using parametric design, machine learning and convolutional neural networks to estimate and optimize building carbon footprint during architectural design.

`Python` `scikit-learn` `Keras` `Rhino` `Grasshopper`
